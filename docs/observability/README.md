# Observability

flowOS separates [operational logs](logging-standard.md), [audit events](audit-events.md), [metrics](metrics.md), [health](health-checks.md), and [correlation](correlation.md). Logs support diagnosis; they are not business truth or durable audit history.

See the platform guidance for [API](api-observability.md), [web](web-observability.md), [mobile](mobile-observability.md), [desktop](desktop-observability.md), and [offline sync](offline-sync-observability.md), plus [privacy/redaction](privacy-redaction.md), [incident diagnostics](incident-diagnostics.md), and the [current audit](current-observability-audit.md).
